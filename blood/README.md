# Blood Transcriptome Analyses

Six blood transcriptome datasets + one cross-cohort synthesis layer:

| Directory | Dataset | Role |
|---|---|---|
| `GSE98793/` | Blood microarray (GPL570) | Discovery screen cohort 1 |
| `GSE39653/` | Blood microarray (GPL10558) | Discovery screen cohort 2 |
| `GSE19738/` | Blood microarray, basal only (GPL6848) | Third microarray cohort |
| `GSE251778/` | Blood RNA-seq (NovaSeq) | RNA-seq follow-up; paired with GSE251780 |
| `GSE61672/` | Community blood microarray | Anxiety boundary (GAD-7 / case-control) |
| `GSE228702/` | Blood 3′-RNA-seq | Social anxiety × early-life adversity factorial |
| `cross_cohort/` | — | Blood OXPHOS cross-cohort synthesis (CAMERA/FRY, singscore meta, HC3, cell-proxy) |

Each dataset README lists its scripts with inputs and outputs.
