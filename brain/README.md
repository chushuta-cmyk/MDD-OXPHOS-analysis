# Postmortem Brain Analyses

Three brain datasets (7 OXPHOS comparisons) + brain boundary synthesis:

| Directory | Dataset | Role |
|---|---|---|
| `GSE53987/` | Brain microarray (GPL570) | HIP / BA46 / associative striatum, tetrad design |
| `GSE54563/` | Brain microarray (GPL6947) | Anterior cingulate cortex, matched pairs |
| `GSE80655/` | Brain RNA-seq (counts) | AnCg / nAcc / DLPFC |
| `cross_cohort/` | — | Brain boundary synthesis |

Each dataset README lists its scripts with inputs and outputs.
